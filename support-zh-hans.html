Environment

系统要求

  • 平台: iPhone / iPod touch。iPad 上的行为取决于设备和系统支持。
  • 操作系统: 当前 App Store 版本需要 iOS 17 或更高版本。
  • 网络: 更新列表、在线文章、源网站、购买、广告和已保存搜索需要网络。离线仅支持已保存副本。
  • 源网站: Wikidot 等源网站的布局变化或维护可能暂时导致显示异常或加载变慢。

FAQ

常见问题

需要账户或登录吗？
不需要。SCP Docs 支持在没有 Wikidot 账户的情况下阅读。编辑文章或发表评论须遵守相应源网站规则。
支持哪些分部和语言？
统一的阅读流程支持英语主站，以及日语、法语、俄语、韩语、西班牙语、波兰语、简体中文、泰语、德语、意大利语、葡萄牙语、越南语、捷克语、繁体中文、土耳其语和印度尼西亚语分部。
如何使用档案和资料库？
在首页选择分部，然后浏览 SCP、Tales、Canons、GoI、合集及其他目录。如果知道编号、标题或标签，请使用搜索。文章可保存、评分、添加备忘录或整理至文件夹。
列表过旧或无法加载
目录数据会在线下载并缓存在设备中。请检查网络，在设置中刷新目录或重启应用。源网站变化可能需要后续目录更新。
哪些功能免费，Premium 提供什么？
阅读、按编号和标题搜索及基础资料库功能免费。Premium 可移除广告，并提供高级搜索、备忘录、更高上限、离线副本、统计、朗读、提醒和 iCloud 文件夹。
如何离线阅读？
离线保存属于 Premium。无网络时只能打开预先保存 HTML 副本的文章；图片、外部资源、未保存文章及目录更新仍需网络。
如何移除广告？
免费使用时可能显示横幅、内嵌、原生、插页及激励广告。有效的月度 Premium 会隐藏广告。激励广告有时可临时解锁 Premium。
已保存搜索和通知如何工作？
此 Premium 功能在同步后于设备上检查目录，并可通知新结果。需要 iOS 通知权限；通知不是由运营者服务器生成的。
我的数据会发送到哪里？
历史、进度、评分、书签、备忘录、统计、已保存搜索和离线副本主要保存在设备上。若 iCloud Drive 可用，部分阅读数据和文件夹可通过你的 iCloud 同步。详情请参阅隐私政策。

Reference

权利、正式文本、作者署名、警告及许可由各源网站规定。SCP Docs 只帮助导航和保存个人阅读状态，不替代源网站规则。
