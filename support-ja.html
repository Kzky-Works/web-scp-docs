Environment

動作環境

  • プラットフォーム: iPhone / iPod touch。iPad での挙動は端末と OS の対応状況に依存します。
  • OS: 現在の App Store 版は iOS 17 以降を対象としています。
  • 通信: 一覧更新、オンライン記事表示、元サイトコンテンツ、購入、広告、保存検索チェックに必要です。オフライン読書は保存済みスナップショットがある記事のみ利用できます。
  • 元サイト: Wikidot など提供元サイトのレイアウト変更やメンテナンスにより、一時的に表示問題や読み込み遅延が起きる場合があります。

FAQ

よくある質問

アカウントやログインは必要ですか？
不要です。SCP Docs は Wikidot アカウントなしで閲覧できるよう設計しています。記事編集やコメント投稿は、各公式サイトの規則に従います。
どの支部と言語に対応していますか？
英語本家 SCP Foundation アーカイブと、日本・フランス・ロシア・韓国・スペイン・ポーランド・中国・タイ・ドイツ・イタリア・ポルトガル・ベトナム・チェコ・繁体字中国・トルコ・インドネシア支部に対応しています。支部を切り替えると、ホーム、検索、アプリ内リスト、記事リンク先、アプリUI言語が切り替わります。データがある範囲で SCP International や翻訳アーカイブの入口も整理します。
SCP記事を探して読む
番号・タイトル・タグ・Object Class・長さ・Wiki評価で探す検索は無料です。履歴、好み度、読書リマインド、ウィジェット、観測記録のサマリー・活動ログ・積読も無料。お気に入りは20件、後で読むは100件まで保存できます。
Premium
プレミアムは広告非表示、ハイライト・メモ作成、読み上げ、オフライン保存、フォルダ、メモ検索・自分の記録での絞り込み、保存検索・新着通知、観測記録の詳しい分析に対応。お気に入り・後で読むの購読上限はありません（各一覧の安全上限10,000件）。月額・年額から選べます。
ひとつの画面から共有
記事URL・タイトル・本文・メモ・ハイライトを個別に選択し、次回も設定を保持できます。プレビューを確認して、標準の共有、コピー、ファイル保存、登録済みの共有先への保存を実行します。同じ画面からカード・投稿の編集にも進めます。本文はリーダーで表示準備が整った現在の1記事から取得し、書庫の複数記事を自動取得しません。

Reference

元コンテンツが正本です

権利、公式本文、著者表示、警告、ライセンス表記は各提供元サイトが正本です。SCP Docs はナビゲーションと個人の読書状態を補助するリーダー層であり、元サイトの規則を置き換えるものではありません。
