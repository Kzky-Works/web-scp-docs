Environment

系統需求

  • 平台: iPhone / iPod touch。iPad 上的行為取決於裝置與系統支援。
  • 作業系統: 目前 App Store 版本需要 iOS 17 或以上版本。
  • 網路: 更新清單、線上文章、來源網站、購買、廣告與已儲存搜尋需要網路。離線僅支援已儲存副本。
  • 來源網站: Wikidot 等來源網站的版面變更或維護可能暫時造成顯示異常或載入變慢。

FAQ

常見問題

需要帳號或登入嗎？
不需要。SCP Docs 支援在沒有 Wikidot 帳號的情況下閱讀。編輯文章或發表留言須遵守相應來源網站規則。
支援哪些分部和語言？
統一的閱讀流程支援英語主站，以及日語、法語、俄語、韓語、西班牙語、波蘭語、簡體中文、泰語、德語、義大利語、葡萄牙語、越南語、捷克語、繁體中文、土耳其語與印尼語分部。
尋找並閱讀SCP文章
編號、標題、標籤、等級、長度與Wiki評分搜尋免費。歷史、個人評分、提醒、小工具、觀測記錄摘要、活動日誌與待讀也免費。收藏20篇，稍後閱讀100篇。
Premium
Premium：去廣告、醒目提示與筆記、朗讀、離線、資料夾、筆記與個人記錄搜尋、儲存搜尋與新結果提醒、詳細分析。收藏與稍後閱讀無訂閱配額（每列表安全上限10,000篇）。月度或年度訂閱。
6.0.2
分享時可分別選擇文章網址、標題、內文、筆記及螢光標記，並保留設定供下次使用。 將分享、複製、儲存檔案及儲存到已登錄目的地整合於同一畫面，改善了預覽與卡片貼文的入口。

Reference

來源內容始終具有權威性

權利、正式文本、作者署名、警告與授權由各來源網站規定。SCP Docs 僅協助導覽與保存個人閱讀狀態，不取代來源網站規則。
